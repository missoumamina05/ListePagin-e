Description du projet :
Ce projet implémente une liste paginée selon les exigences du devoir 2.
Les classes Bloc<T>, Emplacement<T> et ListePaginee<T> permettent de gérer
l’ajout, la recherche, la suppression, le compactage et le comptage des éléments.
La classe Chat est utilisée comme type d’exemple pour tester la structure.

Contenu de l’archive :
- amina.missoum.devoir2.sln
- Dossier du projet C#
- Program.cs contenant les tests demandés
- readme.txt

Fonctionnalités réalisées :
- Ajout dans la première case libre
- Recherche simple et par prédicat
- Recherche de toutes les occurrences
- Suppression via Emplacement<T>
- Compactage des blocs
- Comptage des éléments et des blocs

Instructions :
Ouvrir la solution dans Visual Studio 2022 et exécuter Program.cs.
